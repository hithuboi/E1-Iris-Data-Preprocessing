# Iris Data Preprocessing

## Experiment 1 — Data Science Lab

### Objective

To perform data preprocessing on the Iris dataset, identify and fill missing values, identify correlated numeric features, and visualize the correlation matrix using a heatmap.

### Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Scikit-learn

### Experiment Tasks

1. Load the Iris dataset.
2. Identify missing values.
3. Fill missing values using a suitable method.
4. Identify correlated numeric features.
5. Visualize the correlation matrix using a heatmap.

### Project Structure

```text
data/        - Dataset
notebooks/   - Jupyter Notebook
outputs/     - Heatmap and results
```

### How to Run

Install the required libraries:

```bash
pip install -r requirements.txt
```

Run the Jupyter Notebook:

```bash
jupyter notebook
```

Open `notebooks/iris_preprocessing.ipynb` and execute all cells.

### Results

* Missing values identified and handled.
* Correlated features identified.
* Correlation heatmap generated.
